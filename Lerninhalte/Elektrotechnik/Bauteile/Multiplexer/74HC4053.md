Der **74HC4053** bzw. **74HCT4053** ist ein **dreifacher analoger Umschalter** (**3× SPDT**, *single-pole double-throw*).  
Er kann sowohl als **[[Multiplexer]]** (Viele-zu-eins) als auch als **[[Demultiplexer]]** (Eins-zu-viele) genutzt werden, weil die Schalter **bidirektional** sind.

> Merksatz: Das [[Integrierter Schaltkreis|IC]] „ist“ eigentlich ein **[[Analogschalter]]** – ob du es als **[[Multiplexer|MUX]]** oder **[[Demultiplexer|DEMUX]]** verwendest, hängt davon ab, wo du dein [[elektrische Signale|Signal]] einspeist.

# Grundidee / Kanalaufbau

Es gibt **3 unabhängige Kanäle**: Kanal 1, 2, 3.

Jeder Kanal hat:
- zwei Anschlüsse: \(nY0\), \(nY1\)
- einen gemeinsamen Anschluss: \(nZ\)
- einen Selekteingang: \(S_n\)

Zusätzlich gibt es:
- gemeinsames Enable: \(E\) (**aktiv LOW**)

# Pins / Signalnamen (logisch)

| [[elektrische Signale\|Signal]] | Bedeutung                                            |
| ------------------------------- | ---------------------------------------------------- |
| $1Y0, 1Y1, 1Z$                  | Kanal 1 (Y0/Y1 ↔ Z)                                  |
| $2Y0, 2Y1, 2Z$                  | Kanal 2 (Y0/Y1 ↔ Z)                                  |
| \(3Y0, 3Y1, 3Z\)                | Kanal 3 (Y0/Y1 ↔ Z)                                  |
| \(S1, S2, S3\)                  | Selekt pro Kanal                                     |
| \(E\)                           | Enable (aktiv LOW): schaltet *alle* Kanäle gemeinsam |
| \(VCC, GND, VEE\)               | Versorgung (analog/digital)                          |

# Funktionstabelle (pro Kanal)
Wenn \(E = L\) (enabled):

| \(S_n\) | Verbindung       |
| ------- | ---------------- |
| \(L\)   | \(nY0\) ↔ \(nZ\) |
| \(H\)   | \(nY1\) ↔ \(nZ\) |

Wenn \(E = H\): **alle Schalter AUS** (keine Verbindung).

# Als [[Multiplexer|MUX]] vs. [[Demultiplexer|DEMUX]] benutzen

## Als [[Multiplexer]] (Viele-zu-eins)
- Quellen an \(nY0\) und \(nY1\)
- Ausgang/Bus an \(nZ\)
- \(S_n\) wählt, welche Quelle auf \(nZ\) liegt

## Als [[Demultiplexer]] (Eins-zu-viele)
- Eingang an \(nZ\)
- zwei Ziele an \(nY0\) und \(nY1\)
- \(S_n\) wählt, auf welches Ziel das [[elektrische Signale|Signal]] geht

> Wichtig: Es ist **kein klassischer „1:4 [[Demultiplexer|DEMUX]]“**, sondern pro Kanal nur **ein Umschalter zwischen zwei Wegen** (SPDT).

# Enable / Abschalten

- \(E = H\): alle Kanäle sind aus (praktisch für „Mute“, Trennen, Signal-Gating)
- \(E = L\): normale Umschaltfunktion aktiv

# Versorgung (Kurzüberblick)

- \(VCC\): positive Versorgung
- \(GND\): Masse
- \(VEE\): negative Versorgung oder \(0\ \text{V}\) (je nach Anwendung)

Damit kann der Analogsignalbereich typischerweise zwischen \(VEE\) und \(VCC\) liegen.

# Typische Anwendungen

- Analoges Umschalten (Audio, [[Sensoren]], Messsignale)
- Digitales Umschalten (wenn Pegel im erlaubten Bereich liegen)
- Signal-Gating / Trennen von Leitungen
- Auswahl zwischen zwei Signalpfaden (z. B. Messgerät A/B, Input A/B)

# Abgrenzung / Begriffe
- **Passender Bauteilbegriff:** *„3×SPDT [[Analogschalter]]“*
- **„MUX/DEMUX“** beschreibt die **Verwendung**, nicht dass es intern ein klassischer \(m:1\) oder \(1:n\) Block wäre.
