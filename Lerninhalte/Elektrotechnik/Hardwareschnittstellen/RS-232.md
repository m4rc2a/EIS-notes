**[[RS-232]]** ist eine [[Hardwareschnittstellen|Hardwareschnittstelle]], die zur übertrageung [[UART]] spricht
# Eigenschaften

| **Eigenschaftsbezeichnung**                    | Eigenschaft                                                                                                             |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **OSI‑Schicht** (siehe [[OSI-Referenzmodell]]) | Physikalische Schicht (Electrical/PHY), nicht das Protokoll                                                             |
| **Signalführung**                              | Single‑Ended (unbalanced)<br>-> Asymmetrisch<br>-> einadrige Signalführung                                              |
| **Signalreferenz**                             | $U_{\mathrm{GND}}$ (gegen GND)                                                                                          |
| **mögliche Topologien**                        | Typisch Punkt‑zu‑Punkt, Bus-/Multipoint‑Topologien sind bei RS‑232 **nicht vorgesehen** und in der Praxis störanfällig. |
| **Duplex**                                     | Vollduplex                                                                                                              |
| **Richtungssteuerung**                         | Normalerweise keine (weil Vollduplex). Keine Driver‑Enable‑Umschaltung wie bei RS‑485.                                  |
| **Teilnehmerfähigkeit**                        | Nicht multipoint‑fähig (genormt für 1 Sender ↔ 1 Empfänger).                                                            |
| **Terminierung**                               | Keine Terminierung                                                                                                      |
| **Biasing / Fail-safe**                        | Untypisch                                                                                                               |
| **Typische Protokolle „darauf“**               | [[UART]], NMEA‑0183 (GPS), proprietäre Protokolle; teils auch Modbus RTU                                                |

# Telegrammaufbau

| Start Bit                                                                                                                                                                                                                                                                                                                                                                                        | Data Frame                                                                                                                                                                                                                                                | Parity Bits                                                                                                                                                   | Stop Bits                |                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The [[UART]] data transmission line is normally held at a high voltage level when it’s not transmitting data. To start the transfer of data, the transmitting [[UART]] pulls the transmission line from high to low for one clock cycle. When the receiving [[UART]] detects the high to low voltage transition, it begins reading the bits in the data frame at the frequency of the baud rate. | The data frame contains the actual data being transferred. It can be 5 bits up to 8 bits long if a parity bit is used. If no parity bit is used, the data frame can be 9 bits long. In most cases, the data is sent with the least significant bit first. | Parity describes the evenness or oddness of a number. The parity bit is a way for the receiving [[UART]] to tell if any data has changed during transmission. | To [[elektrische Signale | signal]] the end of the data packet, the sending [[UART]] drives the data transmission line from a low voltage to a high voltage for at least two bit durations. |
# Ablauf
## Parallel zu Seriell
-> Daten werden vom Bus empfangen
## Datenergänzung
[[UART]] ergänzt Daten (je nach Konfiguration) um:
	- Startbit
	- Paritätsbit
	- Stopbit
## Serielle Übertragung
- Das komplette Datenpaket wird nun seriell übertragen
- Der Empfänger nimmt die Daten in seiner konfigurierten Baudrate auf
## Datenwandlung
Der Empfänger löscht nun die drei Komponenten:
- Startbit
- Paritätsbit
- Stopbit
## Seriell zu Parallel
Das Datenpaket wird anschließend auf dem Datenbus bereitgestellt
